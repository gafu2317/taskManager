# TaskManager - スマートタスク管理アプリ

## 概要
重要度とコストを軸にした効率的なタスク管理を実現するWebアプリケーション

## 主な機能
- **スマートタスク管理**: 重要度(1-5) × コスト(1-5) でタスクを整理
- **AIタグ提案**: タスク内容を分析して適切なタグを自動提案
- **柔軟な認証**: ゲストモード or ユーザー登録で選択可能
- **自動延長認証**: 1週間の有効期限が自動で延長される便利なログイン

## 技術スタック
- **フロントエンド**: Next.js 14 + TypeScript + TailwindCSS
- **バックエンド**: Go + Gin + AWS Lambda
- **データベース**: DynamoDB
- **認証**: JWT (自動延長機能付き)
- **インフラ**: AWS + Vercel

## システム特徴
### 重要度・コスト軸でのタスク分析
```
高重要・低コスト → 最優先実行
高重要・高コスト → 分割検討  
低重要・低コスト → 隙間時間活用
低重要・高コスト → 実行検討
```

### ハイブリッド認証システム
- **ゲストモード**: 登録不要、即座に利用開始
- **ユーザー登録**: データの永続化、デバイス間同期
- **アップグレード**: ゲスト→登録ユーザーへの移行可能

## アーキテクチャ
```
Frontend (Next.js) ←→ API (Go/Lambda) ←→ DynamoDB
     ↑                                      ↑
   Vercel                                AWS
```
