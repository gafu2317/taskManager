# taskManager

## 概要

タスク管理を楽しく効率的にするWebアプリケーション。

## 解決する課題

多くの人がタスク管理ツールを使い始めても、途中で挫折してしまう問題に着目しました。主な原因は以下の3点です。

1. **タスク管理画面を開くのが面倒**
2. **ただタスクを記録するだけで終わってしまう**
3. **タスクを追加しても完了させるのを忘れる**

## 解決策

### 1. タスク管理を楽しくする
- **ポップなデザイン**: 視覚的に楽しい画面設計（物理演算バブル表示）
- **ちびキャラ育成機能**: タスク完了でポイントが貯まり、キャラが成長する

### 2. 効率的なタスク管理
- **コスト × 優先度の可視化**: タスクの重要度と所要時間を 1〜5 の数値で設定
- **タグ管理**: 使用頻度に応じたタグを自動記録

### 3. タスク完了の習慣化
- **BGM機能**: YouTube動画IDを登録して作業用BGMを再生
- **常駐キャラクター**: 画面を開き続けやすくし、タスク完了を自然に促す

## 実装済み機能

### タスク管理
- タスクの作成・編集・削除・完了管理
- 重要度（1〜5）とコスト（1〜5）の設定
- タグ付け（使用頻度・最終使用日を自動記録）
- 物理演算バブル表示（サイズ = 重要度 / コスト の比率）
- タスクフィルタリング（タグ・完了状態・重要度・コスト）

### 投げ込み箱
- タイトルのみのクイック入力（Enterで即追加）
- LocalStorageで保存（ゲスト対応）
- 「タスクにする」でTaskFormに引き継ぎ、昇格後は自動削除

### タスク分割（AIサブタスク生成）
- タイトル・説明・タグを入力するとLLMが具体的なサブタスクに自動分割
- 生成されたサブタスクをドラッグ&ドロップで並び替え
- タイトル・説明・重要度・コストを編集後、一括登録
- タイトル・説明の入力中にAPIでタグを自動提案

### 作業時間記録
- ポモドーロタイマー（作業・休憩の切り替え）
- 作業セッション記録（開始/終了時刻・作業時間・休憩時間をDynamoDBに保存）
- 作業終了時に「タスク完了するか」確認モーダル
- 過去10週間の日別作業時間ヒートマップ（6段階の濃淡）
- BGMプリセット管理（YouTube動画IDで登録・再生）

### 習慣化
- 習慣の作成・管理（タイトル / ミニ版 / フル版の3段階）
- 日々の達成記録（ミニ or フルを選択して記録）
- 連続達成ストリークの計算・表示（7日ごとにマスコット台詞発動）
- 過去30日間のヒートマップ表示（フル達成=緑、ミニ達成=黄）
- 習慣の卒業機能（最高ストリークを記録し「殿堂入り」に表示）

### マスコット育成
- ポイントシステム
  - タスク完了: +10pt
  - 作業セッション（30分ごと）: +10pt
  - ログインボーナス（日次）: +5pt
- 性格プリセット: `flat` / `genki` / `amaenbou` / `tennen` / `tsundere` / `majime` / `nekketsu` / `cool`
- アクセサリショップ: ribbon(30pt) / hat(50pt) / glasses(80pt) / scarf(40pt) / crown(200pt)
- スロット解放: 最大3スロット（スロット2: 500pt / スロット3: 1000pt）
- 各機能（タスク完了・習慣達成・作業開始など）でマスコット台詞連動

### 認証
- ゲストモード（UserIDをローカル生成）
- Google認証（next-auth）、ログイン時にゲストデータをDynamoDBへ自動移行
- 5件以上タスク作成でユーザー登録を促すポップアップ表示
